# Versão curta para redes (Instagram / LinkedIn / Status do WhatsApp)

```
GANCHO (1 linha, pergunta ou situação): [...]
TEXTO (até 120 palavras, 3-5 frases curtas ou 3 tópicos com o passo prático): [...]
FECHO: Texto completo no blog: [link]. Salve e mande para quem precisa saber disso.
— [Aline Camargo, Advogada Previdenciária | Camargo Lourenço Advogados] ou [Lislie Lourenço, Advogada Trabalhista | Camargo Lourenço Advogados] ou [Aline Camargo, Advogada Tributária | Camargo Lourenço Advogados]
HASHTAGS: 5 a 8 (#INSS #direitoprevidenciario #Barueri ...)
SUGESTÃO DE IMAGEM/CARROSSEL: [3-5 telas: pergunta → resposta → passo a passo → aviso "cada caso é analisado individualmente"]
```

"Mande para quem precisa" é o gatilho de indicação permitido: incentiva compartilhar informação, não contratar.
