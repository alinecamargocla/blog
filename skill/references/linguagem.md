# Linguagem que conecta

- Leitor-alvo: trabalhador(a) ou aposentado(a), ensino médio, lendo no celular, preocupado(a).
- Comece pela situação da pessoa: "Você foi demitido e a empresa não pagou a rescisão?"
- Frases de até ~20 palavras. Parágrafos de até 3 linhas no celular.
- Use "você". Fale de gente real: "a dona Maria que trabalhou 20 anos sem carteira" (personagem genérico, nunca cliente real).
- Explique termos na hora: "CNIS (o extrato com todas as suas contribuições)".
- Prefira verbo a substantivo: "peça" em vez de "efetue o requerimento".

## Troque o juridiquês
| Evitar | Usar |
|---|---|
| requerimento administrativo | pedido no INSS |
| indeferimento | negativa |
| segurado | quem contribui para o INSS / você |
| verbas rescisórias | dinheiro da rescisão (saldo, férias, 13º...) |
| reclamação trabalhista | processo na Justiça do Trabalho |
| prazo prescricional | prazo para entrar com o processo |
| benefício por incapacidade temporária | auxílio-doença (benefício por incapacidade temporária) |
| benefício assistencial ao idoso/deficiente | BPC/LOAS |
| outrossim, destarte, ademais | além disso, por isso |
| ensejar | causar, dar direito a |
| executado | quem está sendo cobrado no processo |
| Certidão de Dívida Ativa (CDA) | documento da dívida cobrada pelo governo (CDA) |
| penhora | bloqueio de bens ou dinheiro |
| moléstia grave | doença grave |
| repetição de indébito | pedido para receber de volta o imposto pago a mais |
